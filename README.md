# 🛠️ Tools App

> Aplikasi web tools modern berbasis Next.js dengan TypeScript, TailwindCSS, dan Python backend integration

## 🔥 Features

- ✅ Next.js dengan App Router
- ✅ TypeScript untuk type safety
- ✅ TailwindCSS untuk UI modern
- ✅ Python backend integration
- ✅ Responsive & mobile-friendly

## 📦 Installation

```bash
git clone https://github.com/calvin-aprilian/tools-app.git
cd tools-app
npm install
```

## ⚡ Quick Start

```bash
npm run dev
```

## 🛠️ Tech Stack

- **Frontend:** Next.js, TypeScript, TailwindCSS
- **Backend:** Python
- **Deployment:** Vercel / Railway
