# Tools App

Modern web tools platform built with Next.js, TypeScript, and Python backend integration.

> Fullstack development experience from building secure production applications — authentication, API systems, and payment integrations.

## 🔧 Features

- Next.js App Router + TypeScript
- TailwindCSS modern UI
- Python backend integration

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 🛠️ Stack

Next.js, TypeScript, TailwindCSS, Python
